Auth & Setup
🔐
Register / Sign Up
1
Fill name, email, org name, sector, password
2
Backend creates Organization + User + Membership in one DB transaction
3
Receives JWT access token (30 min) + refresh token (7 days)
4
Stored in localStorage → auto-redirects to Onboarding
Free tier: 20 AI generations / month
↓
🎯
Onboarding (3 Steps)
1
Step 1: Org name, sector, website
2
Step 2: Pick brand tone — Professional / Inspirational / Educational / Conversational
3
Step 3: Add social handles (optional) or Skip
4
Saves to Brand Profile → redirects to /content
↓
🏠
Dashboard
1
Loads 3 APIs in parallel: Analytics + Campaigns + Recent Content
2
Shows real metrics: total generated, active campaigns, avg quality, tokens used
3
AI Usage meter (12/20 used), quick action buttons
4
Quick actions navigate to Generate / Campaigns / Calendar / Brand
Content Creation
✍️
Content Generation
1
Select platform: LinkedIn / Instagram / Twitter / Reel / Carousel / CSR Story / Founder Post
2
Enter topic (min 10 chars), tone, language, optional context
3
Backend builds platform-specific prompt using Brand Profile settings (rule-based, no extra AI cost)
4
Groq AI (llama-3.3-70b, free) generates content → saved to DB → returned
5
Result card: Copy / Save / 👍👎 / Regenerate
Increments org.ai_generations_used in DB
↓ 3 paths from generated content
📅
Schedule Post directly
1
Click "Schedule Post" on result card
2
Pick date + time (datetime picker)
3
POST /content/{id}/schedule → creates CampaignPost with status="scheduled"
4
APScheduler checks every 5 min → auto-marks "published" at scheduled time
↓
🎪
Add to Campaign
1
Click "Add to Campaign" on result card
2
Campaign selector shows existing campaigns (from cache)
3
POST /content/{id}/use-in-campaign → links content to campaign
4
Content shows in Campaign's post list
Management & Tracking
🗂️
Campaigns CRUD
1
Create: Name + Type + Dates + Platforms → instant optimistic UI → POST /campaigns
2
Edit: Click ✏️ → pre-filled modal → PATCH /campaigns/{id}
3
Delete: ConfirmDialog → DELETE → instant removal
4
Status filter: All / Draft / Active / Completed
All CRUD operations use optimistic UI — instant feedback
↓
📆
Calendar View
1
Month grid shows 🔵 post dots + 🌍 festival markers from DB
2
Click any day → side panel shows that day's scheduled posts
3
+ Schedule Post → Modal → platform + content + time → POST /schedule
4
Edit / Delete any scheduled post inline
↓
📜
Content History
1
All past generations persist in DB — survive logout/restart
2
Filter by platform or saved only — GET /content/history
3
Use Again → pre-fills Generate form with same topic + platform
4
Expand full content / Delete (instant optimistic removal)

4
Sign Out → blacklists token → clears session
